## 🚀 গিটহাব (GitHub) এবং ভার্সেল (Vercel)-এ লাইভ হোস্ট করার নিয়ম

### ধাপ ১: গিটহাবে পুশ করুন (Push to GitHub)

আপনার কম্পিউটারের টার্মিনালে এই প্রজেক্ট ফোল্ডারে গিয়ে নিচের কমান্ডগুলো চালান:

```bash
# ১. গিট ইনিশিয়ালাইজ করুন (যদি পূর্বে না করা থাকে)
git init

# ২. সব ফাইল স্টেজিংয়ে যুক্ত করুন
git add .

# ৩. কমিট করুন
git commit -m "feat: VELLURE Enterprise Suite with password security and responsive UI"

# ৪. মেইন ব্রাঞ্চ নির্বাচন করুন
git branch -M main

# ৫. আপনার GitHub রিপোসিটোরির রিমোট ইউআরএল যুক্ত করুন (আপনার গিটহাব লিংক দিন)
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPOSITORY_NAME.git

# ৬. গিটহাবে পুশ করুন
git push -u origin main
```

### ধাপ ২: ভার্সেলে হোস্ট করুন (Deploy on Vercel)

1. [Vercel](https://vercel.com)-এ যান এবং আপনার GitHub একাউন্ট দিয়ে লগইন করুন।
2. ড্যাশবোর্ড থেকে **"Add New..."** বোতামে ক্লিক করে **"Project"** নির্বাচন করুন।
3. আপনার গিটহাব থেকে সদ্য পুশ করা রিপোজিটরিটি খুঁজে নিয়ে **"Import"**-এ ক্লিক করুন।
4. কনফিগারেশন সেটিংস চেক করুন (Vercel স্বয়ংক্রিয়ভাবে ঠিক করে নেবে):
   - **Framework Preset:** `Vite`
   - **Root Directory:** `./`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
5. **Environment Variables (ঐচ্ছিক কিন্তু জেমিনাই AI-এর জন্য প্রস্তাবিত):**
   - Environment Variables সেকশনে যান।
   - Key: `GEMINI_API_KEY`
   - Value: আপনার গুগল জেমিনাই এপিআই কি দিন।
6. **"Deploy"** বোতামে চাপুন। মাত্র ১ মিনিটের মধ্যে আপনার অ্যাপটি লাইভ হয়ে যাবে এবং একটি ফ্রি ডোমেইন (যেমন: `vellure-enterprise.vercel.app`) পেয়ে যাবেন!
